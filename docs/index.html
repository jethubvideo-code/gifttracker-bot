Как это работает

  • Движок на серверах GitHub каждые ~3 минуты проверяет все 120 коллекций Telegram Gifts.
  • Как только подарок улучшают до NFT — событие сразу попадает сюда и в бот @Trackingonebot.
  • Страница обновляет данные сама каждые 30 секунд. Просто оставьте открытой.

Что значат цифры

  • Коллекций — подарков под наблюдением.
  • Апгрейдов — улучшений поймано с запуска ленты.
  • Уведомлений — сообщений доставлено подписчикам.
  • Прогонов — циклов проверки движка.

Бесплатно и без лимитов

  • Все апгрейды всех 120 подарков — бесплатно для всех.
  • Подписка в боте: жми 🔔 Подписки и выбирай подарки.
  • Работает на инфраструктуре GitHub — стабильно 24/7.

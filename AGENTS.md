# gifttracker-bot

Автономный монитор апгрейдов Telegram Gifts → NFT. Работает 24/7 на GitHub Actions, без внешних платформ.

## Структура
- `gift-monitor/actions/full-job.js` — движок: счётчики t.me → детект апгрейдов → доставка уведомлений → коммит данных. Режим эстафеты (chain-relay) внутри одного прогона, коммит каждые ~20с.
- `gift-monitor/actions/new-gift-job.js` — новые лимитки из каталога Fragment (каждые 20 мин).
- `gift-monitor/actions/floors-job.js` — скан флор-цен (каждые 15 мин) → `docs/floors.json` + `docs/floors-hist.json`.
- `gift-monitor/actions/gift-images.js` — обложки всех коллекций → `docs/images.json` (каждые 6ч).
- `.github/workflows/` — расписания (full-monitor — эстафета 24/7, остальные по крону).
- `data/` — состояние движка (state-full.json, subscribers.enc — шифрованный снапшот подписчиков, enabled-full.json — флаг режима).
- `docs/` — сайт-дашборд (GitHub Pages): лента, каталог, аналитика, рынок с флор-ценами.

## Сайт
- `docs/index.html` — единая страница, автообновление каждые 20с, PWA (manifest + sw.js).
- Данные сайт читает из `docs/*.json` (fresh) через источник в base64.

## Правила
- Прогон, стартовавший до пуша, работает на старой версии кода.
- При каждом изменении `docs/index.html` бампать версию кэша в `docs/sw.js`.
- Репо публичный: никаких токенов и ключей в коде. Секреты — только в vars репозитория.
- Терминология владельца: «Флор цена» (не «флоер»).

## Зафиксировано 02.10.2026 — архитектура скорости и автопилот
- **Доставка строго 1:1**: каждый апгрейд = отдельное полное сообщение каждому подписчику. Никакой компрессии, никаких пропусков. Маркер `st.lastSentNum` двигается раз за свип. Очередь FIFO дошьётся полностью.
- **AIMD-контроллер скорости** (как TCP): бакет `RL` сам нащупывает фактический потолок Telegram (+1 сообщ/сек каждые 30с чистого потока до 80; 429 → отступ -3 и запоминание границы `hi`; оттайка границы через 10 мин без 429). Живой ориентир: фактический потолок НЕ 30/сек, логи показали 85+/сек без 429.
- **Кап дренина 60 апгрейдов/свип** + шторм-пропуск: спокойные коллекции (очередь пуста, проверены <30с) не перепроверяются.
- **Приоритет живым юзерам**: `state.seen` (штампы касаний бота из bot.js) сортирует получателей — активные первыми; дормантные 30+ дней — беззвучно и в конце; нет данных = не дормант.
- **Бюджет прогона 30 мин** (BUDGET_MS 1_800_000), yml timeout 35 мин, GUARD-ватчдог порогов не имеет (только живость цепи).
- **Правила владельца неприкосновенны**: все апгрейды всех подарков бесплатно для всех; уведомления без цен; обязательная проверка подписки на @unknowesecret; на сайте нет упоминаний GitHub.
- **Guardian (автопилот-охранник)**: `guardian.js` + `guardian.yml` каждые 6ч сам проверяет живость эстафеты (мертва → перезапуск), сбои прогонов за 12ч, бэклог доставки, пишет `docs/health.json`, шлёт отчёт владельцу ТОЛЬКО при проблемах. `mode=report` — отчёт без вмешательства. Система обновляет и содержит себя сама, 100% GitHub Actions.
